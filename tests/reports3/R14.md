### R14-001 [中] 試作ページで IFC だけが開けない（CSP の connect-src が blob: を許さない枠）。知らせは「WebAssembly が使えない」と誤った理由を言う

### R14-002 [中] 枠の CSP が blob: の Worker を禁じると、起動直後に「メモリが足りない可能性」と赤字が出て、その後に開くファイルは「開いています」のまま永久に止まる
- 種類: バグ／文言  対象: 試作ページ
- 再現: `$W/a13/t_worker.js noblob`（script-src に blob: なし・worker-src なし）。起動 → 15 秒待つ → `pcl_binary.pcd` を開く → `cc_cloud.txt` を開く
- 期待: 「この画面では別スレッドが使えないため開けません」など原因どおりの知らせ。ファイルを開いたら失敗を知らせて順番待ちを進める
- 実際: 何も開いていない起動直後に赤字「読み込みの処理が止まりました。メモリが足りない可能性があります。「表示」の「読み込む最大点数」を減らしてください」。その後 pcl_binary.pcd は進み具合「pcl_binary.pcd を開いています」のまま 35 秒以上（120 秒の試験でも）終わらず、2 つ目も始まらない（Worker は 1 回だけ error を出して死に、以後の postMessage は黙って捨てられる）

### R14-005 [中] wasm が使えない枠で .drc（Draco）を開くと、知らせなしに永久に止まり、以後のファイル（.pcd を含む）も一切開かなくなる
- 種類: バグ  対象: 試作ページで再現（処理は共通なので、アプリ版でも Draco の wasm が失敗すれば同じ）
- 再現: `FILES=laspy_14.laz,dracopy_cloud.drc,pillow_topview.png,gmsh_parts.step,pcl_binary.pcd $W/a13/t_matrix.js nos_nowasm`（script-src に 'unsafe-eval'/'wasm-unsafe-eval' なし）
- 期待: .laz と同じく「この画面では展開用の部品（WebAssembly）が使えないため開けません…」と知らせて次へ進む
- 実際: .laz は正しく知らせる。.drc は進み具合が出たまま 120 秒たっても終わらず、続く .png・.step・.pcd もそれぞれ 120 秒待っても 0 個（順番待ちが詰まる）。開いている点群が 0〜1 個なので「すべて閉じる」も出ず、ページを読み直すしかない
- 場所: src/io/formats/wasm.js:18–21。`DracoDecoderModule({ wasmBinary, onModuleLoaded })` は失敗時に `onAbort` を呼ぶだけで、Promise が resolve も reject もされない（try/catch は同期の例外しか拾わない）。`once('draco')` がこの未決の Promise を覚えるので 2 回目以降も止まる
- 直し方の案: `DracoDecoderModule({ wasmBinary, onModuleLoaded: res, onAbort: e => rej(new Error('WebAssembly: ' + e)) })`。あわせて読み込み 1 件ごとに時間切れ（例: 進み具合が N 秒動かなければ loadFailed）を設けると、同種の詰まりに強くなる
- 確度: 再現済み（$W/out/matrix_nos_nowasm.json）

## 試験の資産
- `$W/regress/run.sh` 1 本で 2 版の作り直し→大きさ→全場面（heavy の順番待ちがあるので 30 分以上かかることがある）
- `lib.js`（A13 の lib を写して改造: 親 8840／子 8841、`?art=nos|sam`、CSP の型 strict/strict_noblob/strict_nowasm/strict_wasmonly/strict_connblob を追加、`?inject=nods|lsthrow|lsjunk` でページの先頭に故障を差し込む）

- はまりどころ: Chromium は `TMPDIR` を短い道（`ln -s $W/tmp /tmp/r14t`）にしないと SIGTRAP で起動しない。Playwright の addInitScript は別オリジンの枠の中では効かなかったので、故障の差し込みは子サーバーが HTML の先頭に入れる。「すべて閉じる」はカードが閉じていると見えないので `el.click()` で押す
- 実機で確かめること: 本物の claude.ai の CSP（connect-src に blob: があるか → R14-001 の影響が決まる）、Safari 16.3 以前・iPad での R14-003
