## 直した試験（主なもの）
- 共通: 画面は全部の点を持たない（0.4.1）→ 全部の座標は `__pcd.call({type:'buffers'})`（`tests/env/harness/browser_read.js`、A13 の lib.js、A01 の fieldBase と合わせて）。`f.sample` は先頭 20 万点だけ
- 共通: カードは 1 枚だけ・「表示」は「視点」と「設定」に分かれた・「画像を保存」はファイルのカード・測っている途中の表示（mLive）はない・「床を z = 0 にする」は画面にない
- A01: double の欄の基準値（fieldBase）を足し戻して比べる。時刻がナノ秒の軌跡は秒に直して比べる。軌跡もシフトを足し戻す。CloudCompare の作り直し（`CC_REGEN=1`）。読めない軌跡（KITTI・pos_log・圧縮 MCAP）は「理由を言って断る」が正解。CloudCompare の ascii PLY は有効数字 6 桁なので許す誤差 1e-4。「点群を開く」で選んだ軌跡は点群として開く（0.4.1 の仕様）。場面ごとに 3 分で打ち切る。`known.tsv` と RESULT.txt の「既知」
- A04: 関数の取り出しで下請けの関数・定数も取り込む（worker）。findCeiling(z, xs, ys)、companionsOf は async、isTrajectory は中身で決める、種類の色は番号、選ぶ操作は 2 段（R7-004）、高さの表は 8 列以上、CR だけの改行、シフトは中央値（settle）。A04-039 は索引のマスの数ではなく「選ぶ操作が固まらない」を時間で見る
- A06: 画面の点の位置は f.sample、「画像を保存」はファイルのカード、コントラストの部品は「視点」のカードで、試験ごとに 15 分で打ち切る。直さないもの（A06-009・025）と画面の明るさの設定（OS に合わせない）は「既知」
- A10: Mac の zip は GitHub Actions で作るので参考。7za は A10 の道具に入れる。実行時の依存なし（ws もない）。WM_CLASS と StartupWMClass は lidar-viewer。起動と終了の試験は「ヒューズの inspect だけ戻した試験用の組み立て」（`release-test/`、作り方は heavy_all.sh）で流す。落ちたときの知らせは「読み込み直す」を押したことにする。Linux では窓のメニューがないことを見る（mac のメニューは mac で）。直さないもの（A10-017・019 の一部）は「既知」、空白のある置き場所（B・C）は参考。設定の置き場所が作れない場所は /proc の下に（リポジトリの中に作らない）
- A11: A11-002 は「補正後の座標」と書いてあり、どの点も同じずらしで出ていること。A11-005 はカードの説明（地図座標の近くを中心に回した値）。A11-010 は画面の試験（level/sparse030_auto）で赤い知らせにならないこと
- A13: 統計は全部の座標で。画像・ラスターと高さの表は 1 m の格子なので「座標が粗い」から除く
- A14: カード 1 枚・「床を z = 0」なし・「画像を保存」はファイルのカード。c7 は 1 段ずつ書き出し、メモリの上限 6 GB
- `tests/env/bin/servedist`（Chromium で開くページの配り口。file:// では別スレッドが動かない）を入れた

## アプリの問題の候補（直していない。提案）
1. 【A10 netlog】起動するたびに redirector.gvt1.com からスペルチェックの辞書を取りに行く。R15-002 で `spellcheck: false` を入れたが止まっていない。案: `session.defaultSession.setSpellCheckerEnabled(false)` か `setSpellCheckerLanguages([])`
2. 【A06-010】900×600 の窓で、ファイルのカードと下の操作の案内が重なる。今日足した「中心の丸・矢印: 中心を動かす」で案内が 2 行になったため
3. 【A09】200 万点を開いた直後の最長の処理が約 4 秒（0.4.0 の記録は 1.5 秒）、「索引まで」5.5 秒（同 1.9 秒）。その間画面が止まる。原因は未調査（0.4.1 の自動補正・天井の検出まわりの可能性）

5. 【A10 roUserData】設定の置き場所を作れないと、何も出さずに終わる（終了コード 0）
6. 【A06-031・030】「反射」で intensity と label を持つファイルのとき label になる／ファイルがないのに「この点群には色分けできる項目がありません」

8. 【A02 画像】ICO（A02 の作った 2 個）が開けない、32 bit BMP の透明な画素を点にする、PNG のガンマ。研究で使わない形式の細部
