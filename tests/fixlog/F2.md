# F2 メッシュ・CAD・画像 修正記録

確かめ方: A02 の `node_probe.mjs`（Node、194 件）を写しで実行（179 件 OK。残りは下の「直さなかったもの」と Node の制約）、
`browser_probe.js`（Chromium、写しの dist）でテクスチャ・付属ファイル・Draco など 30 件、`sample/formats` のメッシュ・図面・画像を Node で開き直し（すべて今までどおり）。

## 直したもの
- B16: 読み方（OBJ/STL/OFF/VTK/glTF/DXF/SHP/PDMS/PSZ/画像/TIFF/Draco/IFC/STEP）を `guard()`（image.js）で包み、英語の内部例外を「○○ のファイルが壊れているか、途中で切れているため開けません」／メモリ不足の文言に。日本語・WebAssembly の知らせはそのまま。FBX/DAE（readWithThree）・SVGZ も日本語に。途中で切った 11 種で確認。
- B40: nodata を画素の型に丸めて比較＋float の ±3.4e38 を除外。ModelTransformation は行列をそのまま使う（南北・回転）、結び点の (I,J) も考慮、PixelIsPoint は半画素ずらさない。PhotometricInterpretation で 16 bit RGB は 8 bit に縮めて色、パレットは ColorMap で色。
- B45: OBJ/OFF の頂点色の 0〜1/0〜255 をファイル全体の最大値で判定・丸め。Kd なし・材質なしの面は灰色 200（面ごとの色）。OFF は見出しの接頭辞（ST/C/N/4/n）で列を決める。テクスチャ: OBJ の vt + map_Kd、glTF の baseColorTexture（TEXCOORD・埋め込み/外部画像、baseColorFactor を掛ける）を、散らした点の UV（重心補間）で画像から色を取る（createImageBitmap+OffscreenCanvas。TGA など自前で読める画像も可）。画像が選ばれていない／読めないときは注記。glTF の baseColorFactor の既定を 1 に。
- B46: STL はサイズが「84+50n」以上で文字に見えなければバイナリ（余分なバイトは注記）。文字 STL のキーワードの大文字小文字を問わない。
- B47: VTK 5.1 の OFFSETS/CONNECTIVITY（文字・バイナリ）。POINT_DATA/CELL_DATA の数で読み、CELL_DATA の値は点の欄・色にしない。LOOKUP_TABLE 行がない SCALARS で値を 1 つ食う誤りも直した。
- B48: glTF LINES は 2 点ずつ別の線分。sparse accessor（bufferView なしも）。scenes なしは親のないノードだけを根に。外部 .bin の名前は大文字小文字を問わない。accessor の数をデータの大きさで確かめる（巨大確保の防止）。
- B49: DXF の OCS（任意軸アルゴリズム）を LWPOLYLINE・CIRCLE・ARC・SOLID・TRACE・2D POLYLINE・INSERT に。SPLINE（有理 B スプライン／通過点）・ELLIPSE・MESH を形に。表示しない図形は種類と数を注記。
- B50: app.js の付属ファイルの判定を「glTF/GLB の buffers・images、.mtl の map_*、DAE/FBX の中に名前があるもの」だけに。参照されない .bin/.tif/写真は普通に開く。.mtl だけを選んだときは「開けない形式」と知らせる。
- B68: OBJ は mtllib に書かれた .mtl だけ（なければ同じ名前の .mtl）を読む。行末の `\` の継続。範囲外の頂点番号の面は捨てる。
- B69: 色つきバイナリ STL: 頭書きに COLOR= があれば Magics 方式、なければ VisCAM 方式（赤が上位）。
- B70: EXT_mesh_gpu_instancing を TRANSLATION/ROTATION/SCALE で複製。知らない必須拡張は断る。
- B71: bulge（LWPOLYLINE・2D POLYLINE）、ACI は AutoCAD の 256 色の表（ezdxf と同じ）、420 のトゥルーカラー（画層も）、ブロック内の画層 0 は INSERT の画層・BYBLOCK は INSERT の色、MINSERT の配列、ポリゴンメッシュ（M×N）、ポリフェースの範囲外の番号（A04-051）。
- B72: TGA の色表（type 1/9）・アルファのビット数 0 の 32 bit・PBM P1 の空白なし・XPM の #RGB/#RRRRGGGGBBBB と X11 の色名。
- B73: PSZ の入れ子 zip を 4 段まで再帰で開き（展開の上限は共通）、参照を「zip の中」「zip のあるフォルダ」の両方で探す。中のファイルの注記をまとめて返す。
- B74: 注記を中身に合わせる（面/線/面と線、点だけの DXF は注記なし、PDMS は mm のときだけ「mm を m に」）。

0.3.1 の検査（checkCount・pixels()・PSZ の展開制限・DXF/PDMS の入れ子制限）はそのまま残した。
