## 直したもの
- B02 残り: Linux のビルドだけ `-c.productName=LiDARViewer`（package.json の dist:linux）→ /opt/LiDARViewer（空白なし）。postinst・AppArmor プロファイル・.desktop の Exec もこのパスになったことを deb で確認。メニューの表示名は `linux.desktop.entry.Name` で「LiDAR Viewer」、app.getName()/userData（~/.config/LiDAR Viewer）は変わらないことを確認。
- B21: mac.extendInfo に日本語の NSLocalNetworkUsageDescription、カメラ・マイク・音声取り込み・Bluetooth の説明文は null で削除（--dir の Info.plist で確認）。LC_UUID の書き換え・Developer ID 署名は未対応。
- B23 / B59(FUSE 2): `toolsets.appimage: "1.0.3"`（静的リンクの type2 runtime）。x64 の AppImage 先頭が runtime と一致し NEEDED なし・libfuse.so.2 の文字列なし。arm64 の runtime も static-pie（libz.so 要求なし）なので arm64 AppImage は残した。
- B58: `signAndEditExecutable:false` → `signExecutable:false`（署名だけ省き、resedit で資源を書く）。win-unpacked の exe が ProductName/FileDescription=LiDAR Viewer・0.4.0・fukuda・アイコン 7 枚になったことを pefile で確認。
- B59: build/icons/16〜512 を作り `linux.icon`。deb に hicolor 16〜512 が入った。depends に libgbm1・`libasound2t64 | libasound2`・libdrm2。`desktopName: lidar-viewer.desktop` + `syncDesktopName`（StartupWMClass=lidar-viewer）。
- B60: win のターゲットを portable + zip（LiDARViewer-<version>-win-x64.zip）。portable は `unpackDirName: LiDARViewer`（version を上げても展開先が同じ→ファイアウォールの許可が続く）。二重起動時の上書きの問題は portable の作りのまま（手順書で zip を勧める）。
- B61: mac だけ最小の日本語メニュー（アプリ・編集・ウインドウ。再読み込み・開発者ツールなし）。実機未確認。
- B62: fileAssociations（pcd las laz e57 ptx pts = Default、ply xyz = Alternate、Viewer）→ .desktop の MimeType・mime XML・Info.plist の CFBundleDocumentTypes。main.js で起動時の argv・second-instance の argv（cwd で解決・file:// URI 可・フラグと存在しないパスは除く）・mac の open-file を受け、画面の隠れた `#pcdOsOpen` に DevTools プロトコルの DOM.setFileInputFiles で入れて `app:openFiles` を送る → preload `window.pcdApp.onOpenFiles/ready` → app.js 末尾で enqueue。ディスク上の File のまま渡るので大きなファイルでも写さない。確認: 相対パスの .laz を起動引数で開く（361,575 点）、2 回目の起動に空白入りの file:// URI + フラグ + 無いファイルを渡す → 1 つ目の窓で ply だけ開く、2 つ目は終了（コード 0）。製品 version（linux-unpacked）でも argv から開けた。
- B93 残り: F12 は `!app.isPackaged || LIDAR_VIEWER_DEVTOOLS=1` のときだけ。製品 version で F12 → 開かないことを確認。
- B94: deb の Section を graphics（packageCategory）、/usr/share/doc/lidar-viewer/copyright（build/linux/copyright）を同梱。build/gen-licenses.cjs で THIRD_PARTY_LICENSES.txt（16 ライブラリ、LGPL/MPL の入手先つき）を作り extraFiles で全 OS の配布物のアプリのフォルダへ。dist 系スクリプトで毎回作り直す。
- F5 依頼: BrowserWindow に backgroundColor '#0e1317'（--bg）と show:false → ready-to-show で表示（4 秒で必ず表示）。getBackgroundColor=#0E1317 を確認。
- 手順書: docs/HOW-TO-OPEN.md（Windows の SmartScreen・Smart App Control・ファイアウォール許可・関連付け、mac の「このまま開く」・quarantine・ローカルネットワーク、Ubuntu deb/AppImage、Raspberry Pi は deb）。

## 利用者が実機で確かめること
1. Ubuntu 24.04: deb を入れ /opt/LiDARViewer から起動（sandbox のエラーなし）、メニューにアイコンが出る、.pcd を右クリック→別のアプリで開く。
2. Ubuntu 22.04/24.04: libfuse2 を入れずに AppImage がダブルクリックで起動する。Raspberry Pi 5: arm64 deb（と arm64 AppImage）が起動する。
3. Windows: zip version の exe のアイコン・タスクマネージャーの名前・ファイアウォールの許可の画面が「LiDAR Viewer」になる。ライブで点が届く。.pcd を「プログラムから開く」で開ける。
4. macOS 15: ライブで日本語のローカルネットワークの確認が出る。メニューが日本語で ⌘R が効かない。Finder の .pcd ダブルクリック・Dock に落として開ける。
5. 起動時に白く光らない。
