## 見つけた問題

### R2-001 [重大] 1 つのファイルの中にローカルの部分と地図座標の部分があると、地図座標の部分が黙って 12.5 cm に丸められる
- 種類: バグ（点群が黙って間違う）／対象: 両方
- 再現: `light node $W/regress/e57_err.mjs $W/data/local_utm_2scans.e57 $W/data/e57_scan2.npy`（スキャン 1 = 原点付近 1,500 点、スキャン 2 = 姿勢で UTM に置いた 5,000 点）。ほかに `$W/data/local_then_utm.xyz`（`regress/shift_err.mjs`）、`$W/data/two_scans_local_utm.ptx`、A01 の `cc/bin_local_utm.bin`（CloudCompare BIN の 2 点群）
- 期待: UTM の部分も 1 mm 以内、または精度が落ちることの注記
- 実際: シフト [0,0,0]、スキャン 2 の最大誤差 0.125 m（BIN は 124.96 mm）。注記なし
- 場所: src/io/sink.js `settle()`（最初の 1,000 点の中央値。L118〜）
- 原因: 中央値はファイルの先頭の 1,000 点だけで決まる。スキャン・点群・部分の並びで先頭が原点付近だと、後の地図座標の部分は float32 のまま（3.8e6 で 0.25 m 刻み）。DXF でも先頭の長い迷い線の上に散らした点で中央値が原点側になる（`$W/data/utm_stray_line.dxf`）
- 直し方の案: settle 後に「シフトからの距離の最大」を数え、1e5 m を超えたら注記を出す。複数の部分を持つ形式（E57・PTX・BIN・PSZ）は部分ごとの中心も見てシフトを決める
- 確度: 再現済み

### R2-002 [重大]（B13 の再発）名前に dem / grid / matrix を含む x y z の CSV が、高さの表として開かれる
- 種類: バグ／対象: 両方
- 再現: `light node $W/regress/probe.mjs $W/data/site_dem.csv`（見出しなし 3 列の x,y,z 5,000 点）。`grid_scan.csv`、見出しが `x [m],y [m],z [m]` の `dem_units.csv` も同じ
- 期待: 5,000 点の点群
- 実際: 「CSV の高さの表（3 列 × 5000 行、1 マス = 1 m）」15,000 点の別の形
- 場所: src/io/formats/ascii.js `looksMatrix`（L14〜21）
- 原因: 名前の語だけで表とみなす（見出しがない・`x [m]` のような単位付きの見出しは x と判定されない）。DEM を x,y,z で書き出した CSV はよくある
- 直し方の案: 名前で決めるのは列が多い（例 8 列以上）ときだけにする。見出しの x 判定を `^x\b` などで単位付きにも合わせる
- 確度: 再現済み

### R2-003 [中]（B37 の直し方の問題）double の欄の基準値の決め方で、時刻の桁が落ちる
- 種類: バグ／対象: 両方
- 再現: `light node $W/regress/field_prec.mjs $W/data/gpsweek.pcd gps_time 345678.1234 1e-4`（GPS 週秒）／`... $W/data/ts_zero_first.pcd timestamp 1.7e9 1e-4`（先頭 1 点だけ 0 の無効値）
- 期待: fields + fieldBase が元の値と 1e-4 s 程度で一致
- 実際: 週秒は fieldBase 0・誤差 0.0156 s・5,000 個の時刻が 17 種類に。先頭 0 のときは fieldBase 0・誤差 0.5 s・2 種類（時刻での色分けが役に立たない）
- 場所: src/io/sink.js `finish()`（`WIDE_OK = 1e6` L12、base = 最小値 L145）
- 原因: 絶対値 1e6 未満は引かない／最小値を基準にするため 0 などの外れ値 1 つで引かなくなる
- 直し方の案: wide の欄は常に基準値を引く。基準は最小値ではなく中央値（または 0 以外の最小値）にする
- 確度: 再現済み

### R2-004 [中] ascii PLY で vertex に list の欄があると、列がずれて座標・色が黙って間違う
- 種類: バグ（第 1 回の A01 のデータで NG だが BUGS.md にないもの）／対象: 両方

- 直し方の案: ascii でも欄ごとに読む（list は先頭の数だけ飛ばす）

### R2-005 [中] Bundler（.out）で色の行がない点があると、以後の点が 1 行ずれて座標が黙って間違う
